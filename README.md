# Le Loisir du Matin

A private daily in four languages, built as a home-screen web app.

- `index.html` is the page source (also published as a Claude artifact).
- `tools/build.py` wraps it into the standalone app in `docs/`, with the latest edition in `docs/data/`.
- `editions/` keeps each day's edition as JSON.

To publish: GitHub → Settings → Pages → Deploy from a branch → `main` / `docs`.
